# 🎬 Smart Movie Ticket Booking System

A Java-based console application designed to simplify movie ticket booking through user authentication, movie and show management, interactive seat selection, booking management, wallet functionality, payment simulation, and an admin dashboard.

## 📌 Project Overview

The Smart Movie Ticket Booking System is a console-based Java application that simulates a real-world movie ticket booking platform.

It provides separate functionalities for users and administrators, allowing users to browse movies, select shows, book seats, manage their wallets, and cancel bookings with applicable refund policies.

Administrators can manage movies, theatres, shows, bookings, users, and revenue information.

## 💸 Cancellation and Refund Policy

| Time Before Show | Refund |
|---|---:|
| 2 hours or more | 75% |
| 20 minutes to less than 2 hours | 50% |
| Less than 20 minutes | Cancellation Not Allowed |

Note: Convenience fees and taxes are non-refundable.
